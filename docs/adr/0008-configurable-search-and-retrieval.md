# Configure discovery separately from page-evidence retrieval

Support SearXNG and Tavily Search as configurable discovery choices, with independently configured extraction including Tavily Extract. This permits a self-hostable discovery route and mixed providers rather than coupling every search to one paid service; discovery results alone never verify offers. Subsequent accepted decisions specify an optional SearXNG Compose profile or external instance, explicitly enabled paid fallback, and built-in page retrieval/structured-data/readable-content extraction without a Tavily dependency.
